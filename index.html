Pega tus claves de Supabase para activar SMS real, chat en tiempo real y fotos en la nube.

1. supabase.com → New Project → deaf-gaming
2. Settings → API → copiar Project URL y anon key
3. Authentication → Providers → Phone → activar
4. Twilio o Vonage para SMS (gratis con trial)
5. Storage → crear buckets: avatars, banners, messages, statuses
